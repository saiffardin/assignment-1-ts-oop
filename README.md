# assignment-1-ts-oop

## Overview

This repository contains my solutions for **Assignment 1: Problem Solving with TypeScript & OOP**.

- **Problem solving:** all 8 problems are in [`solutions.ts`](./solutions.ts). They cover basic types, optional parameters, union types with type narrowing, readonly tuples, generics with rest parameters and `keyof` constraints, interfaces, classes with access modifiers and inheritance, and Promises with `async`/`await`.
- **Blogs:** two posts on TypeScript concepts, linked below.

## Blogs

1. [Type Narrowing in TypeScript](./type-narrowing.md): narrowing types with `typeof`, `instanceof`, and the `in` operator.
2. [Generics in TypeScript](./generics.md): how generics work and how they help with `Promise<T>` responses.
